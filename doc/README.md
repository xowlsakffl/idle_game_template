# 방치형 카드 수집 RPG 문서

이 폴더는 세로형 자동전투 기반 방치형 게임의 1차 MVP 기획과 구현 기준을 정리한다.

현재 목표는 완성형 수집 RPG가 아니라, 게임의 핵심 루프가 실제로 재미와 확장 가능성을 가지는지 검증하는 것이다.

## 문서 목록

- [MVP_SPEC.md](MVP_SPEC.md): 1차 MVP 게임 기획서
- [DATA_TABLES.md](DATA_TABLES.md): 초기 영웅, 적, 스테이지, 뽑기, 레벨업 데이터
- [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md): Unity 구현 순서와 완료 기준

## 확정된 방향

- 화면 방향: 세로형
- 전투 방식: 간단한 자동전투
- 조작 방식: 전투 직접 조작 없음, 성장과 뽑기 중심
- 1차 목표: 로컬에서 플레이 가능한 단일 기기 MVP
- 서버: 1차 MVP에서는 제외
- 결제/IAP: 1차 MVP에서는 제외
- 광고: 1차 MVP에서는 제외

## MVP 범위

- 영웅 3명
- 적 5종
- 스테이지 20개
- 자동공격
- 골드 획득
- 영웅 레벨업
- 간단한 뽑기
- 로컬 저장
- 오프라인 보상

## 냉정한 기준

이 장르는 전투보다 숫자 설계가 핵심이다.

따라서 1차 MVP에서 검증해야 할 것은 다음이다.

- 유저가 1분 안에 전투, 보상, 성장 루프를 이해하는가
- 5분 안에 영웅 레벨업과 뽑기를 모두 경험하는가
- 자동전투가 방치형 게임처럼 계속 진행되는가
- 게임을 껐다 켰을 때 저장과 오프라인 보상이 정상 작동하는가
- 스테이지 20까지 진행하는 동안 성장 압박이 생기는가

그래픽, 이펙트, 사운드, 고급 연출은 이 기준을 통과한 뒤에 붙이는 것이 맞다.
