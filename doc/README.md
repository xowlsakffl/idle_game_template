# 방치형 카드 수집 RPG 문서

이 폴더는 세로형 자동전투 기반 방치형 게임의 1차 MVP 기획과 구현 기준을 정리한다.

현재 목표는 완성형 수집 RPG가 아니라, 자동 진행, 보스 관문, 선택 스테이지 반복 파밍, 성장, 저장, 오프라인 보상이 실제로 작동하는지 검증하는 것이다.

## 문서 목록

- [MVP_SPEC.md](MVP_SPEC.md): 1차 MVP 게임 기획서
- [DATA_TABLES.md](DATA_TABLES.md): 초기 영웅, 적, 스테이지, 보스, 뽑기, 저장 데이터
- [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md): Unity 구현 순서와 완료 기준

## 확정된 방향

- 화면 방향: 세로형
- 전투 방식: 접속 즉시 시작되는 자동전투
- 진행 방식: 자동 진행 모드와 선택 스테이지 반복 모드
- 스테이지 구조: 1차 MVP는 챕터 1의 `1-1`부터 `1-20`까지
- 보스 규칙: `1-20`은 보스 스테이지이며, 실패하면 `1-19`를 반복
- 조작 방식: 직접 전투 조작 없음, 성장과 스테이지 선택 중심
- 1차 목표: 로컬에서 플레이 가능한 단일 기기 MVP
- 서버: 1차 MVP에서는 제외
- 결제/IAP: 1차 MVP에서는 제외
- 광고: 1차 MVP에서는 제외

## MVP 범위

- 영웅 3명
- 일반 적 5종
- 챕터 1 스테이지 20개
- `1-20` 보스 1종
- 자동공격
- 자동 스테이지 진행
- 보스 실패 시 직전 일반 스테이지 반복
- 유저 선택 스테이지 반복 파밍
- 골드 획득
- 영웅 레벨업
- 간단한 뽑기
- 로컬 저장
- 오프라인 보상

## 냉정한 기준

이 장르는 전투보다 숫자 설계와 진행 규칙이 핵심이다.

따라서 1차 MVP에서 검증해야 할 것은 다음이다.

- 유저가 접속하자마자 자동전투가 시작되는가
- 일반 스테이지 할당량을 채우면 다음 스테이지로 자동 이동하는가
- `1-20` 보스 실패 시 `1-19` 반복 파밍으로 자연스럽게 막히는가
- 유저가 이전 스테이지를 선택하면 그 스테이지만 반복 파밍하는가
- 레벨업 후 보스 재도전 가능성이 체감되는가
- 게임을 껐다 켰을 때 진행 상태와 반복 모드가 유지되는가
- 오프라인 보상이 현재 파밍 스테이지 기준으로 지급되는가

그래픽, 이펙트, 사운드, 고급 연출은 이 기준을 통과한 뒤에 붙이는 것이 맞다.
