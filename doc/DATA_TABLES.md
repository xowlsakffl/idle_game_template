## 숫자 표기 규칙

전투력, 공격력, 체력, 피해량, 골드, 경험치책은 A~Z/AB 축약 단위를 쓰지 않는다. 모든 주요 수치는 `1,234` 형태의 일반 숫자로 표시한다. `999,999`는 하드 상한이 아니라 초중반 전투력/재화 규모를 읽기 쉽게 유지하기 위한 소프트 목표값으로 본다.

루비, 뽑기권, 초월석처럼 소량 보유 개수를 직접 확인해야 하는 재화도 같은 일반 숫자 표기를 쓴다. 수치를 강제로 자르지 않고, 스테이지 보상 성장률과 레벨업 비용 곡선으로 인플레이션 속도를 제어한다.

전장 데미지 미터기는 현재 출전한 영웅 전원을 표시하고, 영웅별 직접 공격 누적 피해량을 일반 숫자와 상대 게이지바로 표시한다. 몬스터마다 초기화하지 않고 새 스테이지 시작 시 초기화한다. 자동 스킬과 펫 피해는 영웅별 직접 피해에 임의 배분하지 않는다.
같은 전투 틱에서 공격 가능한 영웅은 먼저 전부 수집한 뒤 공격 묶음으로 처리한다. 이 규칙은 전원 동시 전투 체감을 위한 기준이며, UI도 해당 묶음의 영웅을 함께 공격 모션으로 표시한다.
전장 UI에서 출전 영웅은 특성별 배회 패턴을 가진다. 보이는 몬스터는 사방 외곽 스폰 위치에서 시작해, 자기 현재 위치 기준 가장 가까운 영웅을 어그로 대상으로 선택하고 해당 영웅 주변 오프셋으로 접근한다.
영웅도 자기 현재 위치 기준 가장 가까운 보이는 몬스터를 최초 추적 대상으로 잡는다. 한 번 타깃을 잡은 영웅, 스킬, 펫은 해당 몬스터가 죽을 때까지 같은 `SpawnSequence`를 공격한다. 몬스터 처치로 해당 타깃이 사라진 뒤에만 다음 공격 시 새 타깃을 선택한다.
영웅과 몬스터의 전장 표시 좌표는 프레임마다 저장하고 `MoveTowards` 방식으로 갱신한다. 영웅 표시 이동 속도는 `82 + MoveSpeed * 54` 픽셀/초를 기본으로 하고, 공격 플래시 중에는 공속에 따른 짧은 돌진 속도를 추가한다.
상단 전장 바는 단일 몬스터 HP가 아니라 일반 스테이지 100마리 처치 진행률로 사용한다. 보이는 몬스터 액터는 머리 위에 작은 HP바를 가진다. 일반 스테이지 전투는 최대 `MaxVisibleEnemies`개의 표시 몬스터 HP 슬롯을 유지한다. 몬스터가 처치되면 죽은 위치에 새 몬스터를 놓지 않고, 처치된 수만큼 새 스폰 번호를 발급해 사방 외곽 스폰 위치에서 다시 진입시킨다. 새 스폰은 짧은 등장 보호 시간 동안 공격 대상이 되지 않고, 기존 개체는 `KO` 사망 표시 후 사라진다.

## 영웅 스탯 공식

```text
공격력 = floor((기본 공격력 + (현재 레벨 - 1) * 레벨당 공격력 증가) * (1 + 성급 * 0.06) * 등급 스탯 배율 * 패시브 공격력 배율 * 10성 전체 스탯 배율)
체력 = floor((기본 체력 + (현재 레벨 - 1) * 레벨당 체력 증가) * (1 + 성급 * 0.055) * 등급 스탯 배율 * 패시브 체력 배율 * 10성 전체 스탯 배율)
공속 = 기본 공속 * 등급 공속 배율 * 패시브 공속 배율 * 10성 전체 스탯 배율
이속 = 기본 이속 * 등급 이속 배율 * 패시브 이속 배율 * 10성 전체 스탯 배율
```

패시브 배율은 해당 영웅의 패시브 대상 스탯에만 적용한다. 5성 이상이면 패시브 효과가 50% 강화되고, 10성 이상이면 공격력/체력/공속/이속에 10% 전체 스탯 배율을 적용한다.

## 영웅 성급 비용

모든 영웅은 0성에서 시작하고 최대 15성까지 올릴 수 있다. 성급업은 해당 영웅 조각만 소모한다.
성급 표시는 항상 5칸으로 표시한다. 1~5성은 노란별이 채워지고, 6~10성은 노란 5칸 위에 파란별이 왼쪽부터 덮이며, 11~15성은 파란 5칸 위에 보라별이 왼쪽부터 덮인다. 6성은 첫 번째 별만 파란색이고 오른쪽 4개는 노란색이다.
레벨 상한은 `(현재 성급 + 1) * 50`이다. 0성 상한은 50, 1성 상한은 100, 15성 최종 상한은 800이다.

```text
다음 성급 비용 = 등급별 기본 조각 * 다음 성급
최대 성급 = 15성
```

## 영웅 편성 데이터

| 항목 | 값 |
| --- | ---: |
| 영웅 데이터 수 | 38명 |
| 최대 출전 영웅 | 8명 |
| 프리셋 수 | 3개 |
| 하위 탭 | 편성, 특성, 토템, 룬 |

1차 구현에서는 편성 탭, 특성 탭, 토템 탭, 룬 탭을 실제 UI로 구현한다. 시설은 영웅 하위 탭이 아니라 하단 대메뉴로 관리하고, 사이드킥은 제외한다.
영웅 목록은 한 줄에 6명씩 배치하고, 낮은 등급부터 표시하며, 같은 등급 안에서는 이름 가나다순으로 정렬한다. 미출전 영웅 카드의 `+` 버튼을 누른 뒤 원하는 출전 슬롯을 클릭하면 해당 슬롯에 배치한다. 대상 슬롯에 이미 영웅이 있으면 새 영웅으로 교체한다. 출전 중인 목록 카드는 중앙에 `배치됨` 오버레이를 띄우고 어둡게 처리한다. 출전 슬롯과 출전 중인 목록 카드의 `-` 버튼을 누르면 편성에서 제외한다. `자동 배치` 버튼은 전투력 높은 순서로 영웅을 정렬해 최대 8명까지 편성 초안에 채운다. `일괄 승급` 버튼은 조각이 충분한 모든 영웅을 가능한 성급까지 즉시 승급하고 저장한다. 신규 계정의 1번 프리셋은 시작 전투용 기본 편성으로 취급하고, 저장 이력이 없는 다른 프리셋은 빈 슬롯으로 표시한다. 편성 탭에는 룬 4칸을 표시하고, 룬 슬롯을 누르면 편성 화면 위에 목록 모달을 띄운다. 토템은 장착 슬롯을 쓰지 않고 6종 효과가 전역 적용된다. 편성 변경은 영웅/룬만 화면 안에서 임시 반영하고, 영웅 화면 이탈 시 저장 확인 팝업에서 확인을 누를 때 프리셋별 슬롯을 로컬 저장한다. 저장이 확정되면 현재 스테이지를 다시 시작한다.
영웅 카드 또는 편성 슬롯의 영웅을 클릭하면 상세 정보 화면을 연다. 상세 정보 화면은 전투력, 보유 경험치책, 스킬 정보, 공격력, 체력, 공속, 이속, 5성/10성 해금 효과를 표시한다. 기본 정보 탭 하단에는 `제외`, `레벨업`, `승급` 버튼을 두고, 각각 편성 초안 제거, 경험치책 소모 레벨업, 영웅 조각 소모 승급을 처리한다. 장비 슬롯은 무기, 모자, 갑옷, 장신구, 포션 5개만 UI로 표시하고, 6번째 슬롯과 장비 스탯 전투 반영은 보류한다.

## 영웅 특성 데이터

계정 레벨은 영웅 레벨과 별도로 저장한다. 일반 몬스터 처치와 보스 처치가 계정 경험치를 지급하고, 계정 레벨이 1 오를 때마다 특성 포인트 1점을 얻는다. 이미 찍은 특성 레벨의 총 비용을 뺀 값이 현재 사용 가능한 특성 포인트다.

특성 트리는 19개 뎁스를 가로로 진행하는 연결형 트리다. 뎁스별 노드 수는 `1, 3, 3, 1, 2, 2, 1, 3, 3, 2, 1, 2, 1, 3, 3, 3, 1, 2, 1`이다. 다음 뎁스 전체가 열리는 방식이 아니라, 현재 노드에 선으로 연결된 이전 뎁스 노드 중 하나를 MAX까지 올렸을 때만 해당 노드가 열린다.

| 구조 | 값 |
| --- | --- |
| 총 뎁스 | 19 |
| 총 노드 수 | 36 |
| 해금 규칙 | 연결된 이전 노드 중 1개 MAX |
| 1->N 연결 | 이전 단일 노드가 다음 뎁스 모든 노드에 연결 |
| N->1 연결 | 이전 뎁스 모든 노드가 다음 단일 노드에 연결 |
| 3->2 연결 | 좌측=왼쪽/중앙, 우측=중앙/오른쪽 |
| 2->3 연결 | 좌측=왼쪽, 중앙=왼쪽/오른쪽, 우측=오른쪽 |

| 주요 효과군 | 사용 효과 |
| --- | --- |
| 전투 | 공격력, 치명타 데미지, 최종 데미지, 스킬 데미지 |
| 생존 | 체력, 받는 피해 감소, 이동속도 |
| 보상 | 골드 획득량, 경험치책 획득량, 계정 경험치 획득량 |

| 항목 | 값 |
| --- | ---: |
| 노드 최대 레벨 | 100 |
| 노드 1레벨 비용 | 특성 포인트 1 |
| 계정 레벨 기본값 | 1 |
| 계정 레벨업 경험치 | `ceil(40 * 현재 계정 레벨^1.22)` |
| 일반 처치 계정 경험치 | `floor(2 + 챕터 * 0.5 + 스테이지번호 * 0.08)` |
| 보스 처치 계정 경험치 | 일반 기준 경험치 * 30 |

특성 노드 하나가 MAX일 때 주는 효과는 대략 공격/최종/스킬 4~9%, 체력 8~12%, 보상/경험치 7~10%, 이동속도 2.5~3%, 피해감소 1.2~1.5% 수준으로 제한한다. 특성은 19뎁스 장기 성장축이므로 노드 하나에 25~65%를 주면 계정 레벨 몇십 번만으로 전투 밸런스가 무너진다.

`1-20` 이후는 고정 테이블을 계속 복사하지 않고 절차 생성한다. 모든 챕터는 20스테이지 단위이며, `n-20`은 보스다. 보스를 처치하면 다음 챕터 `n+1-1`로 자동 진행하고, 실패하면 같은 챕터 `n-19`로 내려가 반복 파밍한다.

```text

생성 보스 HP = 같은 전역 번호의 목표 HP * 8
생성 보스 골드 = 같은 전역 번호의 목표 골드 * 8
전역 스테이지 번호 = (챕터 - 1) * 20 + 스테이지 번호
```

실제 `StageDefinition`에는 몬스터/보스 기본 수치에 맞춘 HP/골드 배율을 저장한다. 전투 HP, 피해량, 골드, 경험치책은 내부적으로 `GameNumber`를 유지하되 UI와 밸런스는 6자리 일반 숫자 경제로 제한한다.

## 요새 데이터

요새는 하단 대메뉴 `요새`에서 관리하는 단일 레벨 성장축이다. 성벽, 망루, 석재/목재 강화 같은 부위별 업그레이드는 현재 MVP에서 제외한다.

| 항목 | 값 |
| --- | ---: |
| 시작 레벨 | 1 |
| 최대 레벨 | 300 |
| 레벨업 방식 | 누적 요새 경험치 기준 수동 레벨업 |
| 경험치 소모 여부 | 소모하지 않음 |
| 전투 반영 | 요새 HP, 자동 공격력, 공격 간격, 사거리, 종합 전투력 |
| 저장 키 | `fortress.level`, `fortress.experience` |

```text
다음 레벨 필요 경험치 = ceil(62 * (다음레벨 - 1)^2.08 + 35 * (다음레벨 - 1))
요새 HP = floor(520 + 레벨 * 38 + 레벨^1.22 * 16)
요새 공격력 = floor(12 + 레벨 * 2.6 + 레벨^1.16 * 1.8)
요새 공격 간격 = max(0.82, 2.10 - 레벨 * 0.0065)
요새 사거리 = min(4.35, 2.35 + 레벨 * 0.018)
요새 전투력 = floor(300 + 레벨 * 18 + 레벨^1.08 * 2.6)
```

요새 경험치 보상:

```text
일반 처치 요새 EXP = floor(max(1, 3 + 전역 스테이지 번호 * 0.85))
보스 처치 요새 EXP = 일반 기준 * 24
```

밸런스 메모: 요새는 영웅 성장을 대체하면 안 된다. 현재 역할은 원거리/지원 영웅 보호, 전장 중앙 기준점, 소량의 자동 공격 보조다. 요새 레벨이 보스 클리어의 주된 답이 되면 영웅 수집/장비/룬의 이유가 약해진다.

## 장비 뽑기 데이터

장비는 무기, 모자, 갑옷, 장신구, 포션 5개 슬롯으로 나눈다. 1차 구현에서는 장비별 보유 수량, 레벨, 성급을 저장하고, 캐릭터 상세정보 장비 슬롯에 장착/해제할 수 있다. 장비 스탯의 전투 반영은 다음 단계로 분리한다.
장비는 0성 1레벨에서 시작한다. 레벨 상한은 영웅과 동일하게 `(현재 성급 + 1) * 50`이며, 0성 상한은 50, 1성 상한은 100, 15성 상한은 800이다.
영웅 상세 화면의 장비 탭은 보유 장비 카드를 슬롯별로 필터링한다. 필터는 무기, 모자, 갑옷, 장신구, 포션 5종이다. `+` 버튼으로 장비를 선택하고 같은 부위 슬롯을 클릭하면 장착하며, 장착 중인 장비는 `장착중`으로 표시하고 `-` 버튼으로 해제한다.

```text
장비 공격력 = floor(기본 공격력 * (1 + (레벨 - 1) * 0.01) * (1 + 성급 * 0.055))
장비 체력 = floor(기본 체력 * (1 + (레벨 - 1) * 0.01) * (1 + 성급 * 0.055))
```

## 토템 데이터

토템은 장착물이 아니라 전역 적용되는 계정 성장축이다. 기본 제공 토템은 6종이며, 각 토템은 `커먼 -> 언커먼 -> 레어 -> 에픽 -> 전설 -> 신화`로 진화한다. 각 등급은 `Lv.1~100`을 가진다. 같은 등급의 6개 토템이 모두 `Lv.100`이 되어야 토템 정수를 사용해 다음 등급으로 전체 진화한다. 전체 진화 후 해당 등급의 토템들은 모두 다음 등급 `Lv.1`이 된다.

편성 프리셋별 토템 슬롯은 사용하지 않는다. 과거 저장 키는 세이브 호환용으로만 남기고 전투 계산에는 반영하지 않는다.

레벨업 비용은 `ceil(6 * 등급비용계수 * 현재레벨^1.22)`이다. 진화 비용은 커먼 300, 언커먼 900, 레어 2700, 에픽 8100, 전설 24000 토템 정수다.

## 룬 데이터

룬은 영웅 프리셋별 전투 보정 장치다. 한 프리셋에 4개까지 장착하며, 같은 룬은 같은 프리셋 안에서 중복 장착할 수 없다. 룬에는 레벨과 조각 재화가 없고, 같은 룬 + 같은 등급의 개별 룬을 합성해 다음 등급 룬 1개를 만든다.

## 편성 장착 데이터

편성 탭에서 바꾸는 영웅과 룬은 즉시 저장하지 않는다. 화면을 나가거나 탭을 닫을 때 저장 확인 팝업을 띄우고, 확인하면 두 종류의 편성을 한 번에 저장한 뒤 현재 스테이지를 다시 시작한다. 취소하면 임시 변경을 모두 버리고 저장된 편성으로 되돌린다. 토템은 편성 저장 로직을 타지 않는 전역 성장 요소다.

| 대상 | 슬롯 수 | 선택 UI | 저장 시점 | 전투 반영 |
| --- | ---: | --- | --- | --- |
| 영웅 | 8 | 편성 슬롯/영웅 목록 | 저장 확인 후 | 저장 후 스테이지 재시작 |
| 룬 | 4 | 편성 위 룬 목록 모달 | 저장 확인 후 | 저장 후 스테이지 재시작 |

룬 목록 모달은 현재 프리셋의 임시 장착 상태를 기준으로 `장착됨` 오버레이를 표시한다. 저장 전 임시 변경은 전투 계산에 반영하지 않는다.

## 시설 파견 데이터

시설 파견은 하단 대메뉴 `시설`에서 관리하는 시간 기반 자원 생산 시스템이다.

### 시설 목록

| ID | 표시명 | 생산 자원 | 시간당 기본 생산량 | 생산 주기 | 최대 누적 |
| --- | --- | --- | ---: | ---: | ---: |
| `FAC_REQUEST` | 의뢰소 | 골드 | 1200 | 1시간 | 12시간 |
| `FAC_TRAINING` | 훈련소 | 영웅 경험치책 | 240 | 1시간 | 12시간 |
| `FAC_FORGE` | 대장간 | 장비 경험치책 | 180 | 1시간 | 12시간 |
| `FAC_TOTEM` | 토템 제단 | 토템 정수 | 40 | 1시간 | 12시간 |
| `FAC_RUNE` | 룬 공방 | 룬 상자 | 4 | 1시간 | 12시간 |
| `FAC_TRANSCEND` | 초월 연구소 | 초월석 | 12 | 1시간 | 12시간 |

### 시설 업그레이드

| 목표 레벨 | 재료 |
| ---: | --- |
| 2-5 | 목재 |
| 6-10 | 목재 + 벽돌 |
| 11-15 | 벽돌 + 철재 |
| 16-20 | 목재 + 벽돌 + 철재 |

배치 슬롯 해금:

| 시설 레벨 | 배치 영웅 슬롯 |
| ---: | ---: |
| 1 | 1 |
| 5 | 2 |
| 10 | 3 |
| 15 | 4 |
| 20 | 5 |

생산 공식:

```text
시설 레벨 배율 = 1 + (레벨 - 1) * 0.08
영웅 배치 보너스 = clamp(배치 영웅 생산 점수 합 / 120000, 0, 0.50)
시간당 생산량 = 기본 시간당 생산량 * 시설 레벨 배율 * (1 + 영웅 배치 보너스)
```

영웅 생산 점수는 전투력, 레벨, 성급, 등급만 사용한다. 시설별 선호 특성은 의도적으로 제외한다.

UI 규칙:

- 시설 화면은 세로 카드 리스트다.
- 각 카드는 시설명, 레벨, 생산 자원, 누적 보상, 누적 시간, 배치 인원, 수령 상태, 업그레이드/MAX 상태를 표시한다.
- 하단 액션은 `배치 인력`, `모두 획득`이다.
- `모두 획득` 성공 시 획득한 자원 목록을 팝업으로 요약 표시한다.
- 배치 인력 모달은 시설별 행, 배치 영웅, 잠긴 슬롯을 표시한다.
- `추천 배치`는 유효한 기존 배치를 유지하고, 비어 있는 해금 슬롯만 생산 점수가 높은 영웅으로 채운다.
- `모두 해제`는 모든 시설 배치를 해제한다.

### 저장 키

| 키 | 용도 |
| --- | --- |
| `wood` | 시설 업그레이드용 사냥 자재: 목재 |
| `brick` | 시설 업그레이드용 사냥 자재: 벽돌 |
| `iron` | 시설 업그레이드용 사냥 자재: 철재 |

| `facility.{facilityId}.assignedHero.{slot}` | 슬롯별 배치 영웅 ID |

### 사냥 자재 보상

- 일반 몬스터는 낮은 확률로 목재를 지급한다.
- 보스는 목재를 확정 지급하고, 스테이지가 높아질수록 벽돌/철재 지급량 또는 확률이 증가한다.
- 목재/벽돌/철재는 시설에서 생산하지 않는다.
