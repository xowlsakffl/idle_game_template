# 초기 데이터표

이 문서는 1차 MVP에서 사용할 임시 밸런스 데이터다.

수치는 재미가 검증된 값이 아니라 구현과 테스트를 위한 시작점이다. 실제 플레이 후 반드시 조정해야 한다.

## 영웅 데이터

| ID | 이름 | 역할 | 기본 공격력 | 공격 주기 | 레벨당 공격력 증가 |
| --- | --- | --- | ---: | ---: | ---: |
| H001 | 기사 아렌 | 균형형 | 10 | 1.2초 | 5 |
| H002 | 궁수 리나 | 빠른 공격 | 7 | 0.8초 | 3 |
| H003 | 마법사 노아 | 강한 한방 | 18 | 1.8초 | 8 |

## 영웅 공격력 공식

```text
공격력 = 기본 공격력 + (현재 레벨 - 1) * 레벨당 공격력 증가
```

## 영웅 레벨업 비용

| 레벨 구간 | 비용 공식 |
| --- | --- |
| 1-20 | 20 * 현재 레벨^1.25 |
| 21+ | 1차 MVP 범위 밖 |

구현 편의를 위해 소수점은 버림 처리한다.

```text
레벨업 비용 = floor(20 * 현재 레벨^1.25)
```

## 적 최종 수치 공식

```text
적 HP = floor(적 기본 HP * 스테이지 HP 배율)
처치 골드 = floor(적 기본 골드 * 스테이지 골드 배율)
```

## 뽑기 데이터

1차 MVP에서는 뽑기 결과를 영웅 조각으로 단순화한다.

| 등급 | 확률 | 보상 |
| --- | ---: | --- |
| Common | 70% | 무작위 영웅 조각 1개 |
| Rare | 25% | 무작위 영웅 조각 3개 |
| Epic | 5% | 무작위 영웅 조각 10개 |

## 뽑기 비용

| 종류 | 비용 |
| --- | ---: |
| 1회 뽑기 | 무료 테스트 버튼 |
| 10회 뽑기 | 무료 테스트 버튼 |

1차 MVP에서는 유료 재화와 광고 보상 없이 뽑기 시스템만 검증한다.

## 오프라인 보상 데이터

| 스테이지 구간 | 초당 골드 기준 |
| --- | ---: |
| 1-4 | 현재 스테이지 처치 골드 * 0.20 |
| 5-8 | 현재 스테이지 처치 골드 * 0.25 |
| 9-12 | 현재 스테이지 처치 골드 * 0.30 |
| 13-16 | 현재 스테이지 처치 골드 * 0.35 |
| 17-20 | 현재 스테이지 처치 골드 * 0.40 |

```text
오프라인 보상 = floor(초당 골드 기준 * 오프라인 초)
최대 오프라인 초 = 28800
```
