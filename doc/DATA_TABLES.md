# 초기 데이터표

이 문서는 1차 MVP에서 사용할 임시 밸런스 데이터다.

수치는 재미가 검증된 값이 아니라 구현과 테스트를 위한 시작점이다. 실제 플레이 후 반드시 조정해야 한다.

## 영웅 공격력 공식

```text
공격력 = floor((기본 공격력 + (현재 레벨 - 1) * 레벨당 공격력 증가) * (1 + 성급 * 0.2))
```

## 영웅 성급 비용

모든 영웅은 0성에서 시작하고 최대 5성까지 올릴 수 있다. 성급업은 해당 영웅 조각만 소모한다.

```text
다음 성급 비용 = 등급별 기본 조각 * 다음 성급
```

| 등급 | 기본 조각 | 1성 | 2성 | 3성 | 4성 | 5성 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 언커먼 | 10 | 10 | 20 | 30 | 40 | 50 |
| 레어 | 15 | 15 | 30 | 45 | 60 | 75 |
| 에픽 | 25 | 25 | 50 | 75 | 100 | 125 |
| 전설 | 40 | 40 | 80 | 120 | 160 | 200 |
| 신화 | 60 | 60 | 120 | 180 | 240 | 300 |

## 영웅 레벨업 비용

| 레벨 구간 | 비용 공식 |
| --- | --- |
| 1-20 | 20 * 현재 레벨^1.25 |
| 21+ | 1차 MVP 범위 밖 |

구현 편의를 위해 소수점은 버림 처리한다.

```text
레벨업 비용 = floor(20 * 현재 레벨^1.25)
```

## 적 최종 수치 공식

```text
일반 적 HP = floor(적 기본 HP * 스테이지 HP 배율)
일반 처치 골드 = floor(적 기본 골드 * 스테이지 골드 배율)
보스 HP = floor(보스 기본 HP * 스테이지 HP 배율)
```

## 진행 모드 데이터

| 값 | 이름 | 설명 |
| --- | --- | --- |

| BossBlocked | 보스 막힘 | 보스 실패 후 직전 일반 스테이지 반복 |

## 스테이지 선택 규칙

| 조건 | 결과 |
| --- | --- |
| 유저가 최고 도달 이하 일반 스테이지 선택 | `RepeatSelected`로 변경 후 해당 스테이지 반복 |
| 유저가 최고 도달 이하 보스 스테이지 선택 | 보스 스테이지 재도전 |
| 유저가 자동 진행 재개 선택 | `AutoProgress`로 변경 후 최고 진행 스테이지에서 재개 |
| 보스 실패 | `BossBlocked`로 변경 후 `1-19` 반복 |

| ID | 비용 공식 | 최대 레벨 |
| --- | --- | ---: |
| attackPower | floor(25 * 다음 레벨^1.25) | 1,000,000 |
| maxHp | floor(30 * 다음 레벨^1.25) | 1,000,000 |
| criticalChance | floor(50 * 다음 레벨^1.30) | 500 |
| criticalDamage | floor(75 * 다음 레벨^1.22) | 1,000,000 |
| doubleCriticalChance | floor(100 * 다음 레벨^1.32) | 500 |
| doubleCriticalBonusDamage | floor(100 * 다음 레벨^1.22) | 1,000,000 |
| finalDamage | floor(150 * 다음 레벨^1.28) | 1,000,000 |

성장 레벨업 UI는 `1x`, `10x`, `100x`, `1000x` 단위를 제공한다. 단위 선택 버튼은 골드 보유량과 관계없이 항상 선택 가능하다. 선택한 단위 전체 비용을 낼 수 있을 때만 구매하고, 골드가 부족한 성장 행은 회색으로 표시한다. 회색 성장 행을 누르면 `골드가 부족합니다.` 문구를 띄운다. 성장 행의 오른쪽 버튼 문구는 `10x UP` 같은 액션 문구가 아니라 해당 단위의 업그레이드 비용만 표시한다.

## 오프라인 보상 데이터

보스 스테이지는 오프라인 보상 기준으로 사용하지 않는다. 현재 위치가 보스라면 직전 일반 스테이지를 기준으로 계산한다.

| 스테이지 구간 | 초당 골드 기준 |
| --- | ---: |
| 1-1 ~ 1-4 | 현재 스테이지 처치 골드 * 0.20 |
| 1-5 ~ 1-8 | 현재 스테이지 처치 골드 * 0.25 |
| 1-9 ~ 1-12 | 현재 스테이지 처치 골드 * 0.30 |
| 1-13 ~ 1-16 | 현재 스테이지 처치 골드 * 0.35 |
| 1-17 ~ 1-19 | 현재 스테이지 처치 골드 * 0.40 |

```text
오프라인 보상 = floor(초당 골드 기준 * 오프라인 초)
최대 오프라인 초 = 28800
```
