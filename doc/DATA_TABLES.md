# 초기 데이터표

이 문서는 1차 MVP에서 사용할 임시 밸런스 데이터다.

수치는 재미가 검증된 값이 아니라 구현과 테스트를 위한 시작점이다. 실제 플레이 후 반드시 조정해야 한다.

## 숫자 표기 규칙

`1000 = 1A`로 시작해 1000배마다 `B`, `C`, `D` 순서로 올라가며 최대 `Z`까지 사용한다. 전투력, 공격력, 체력, 피해량, 성장 수치 표시는 이 규칙을 공통 적용한다.

## 영웅 스탯 공식

```text
공격력 = floor((기본 공격력 + (현재 레벨 - 1) * 레벨당 공격력 증가) * (1 + 성급 * 0.2) * 패시브 공격력 배율)
체력 = floor((기본 체력 + (현재 레벨 - 1) * 레벨당 체력 증가) * (1 + 성급 * 0.15) * 패시브 체력 배율)
공속 = 기본 공속 * 패시브 공속 배율
이속 = 기본 이속 * 패시브 이속 배율
```

## 영웅 성급 비용

모든 영웅은 0성에서 시작하고 최대 15성까지 올릴 수 있다. 성급업은 해당 영웅 조각만 소모한다.
성급 표시는 1~5성 노란별, 6~10성 파란별, 11~15성 보라별로 구분한다.

```text
다음 성급 비용 = 등급별 기본 조각 * 다음 성급
최대 성급 = 15성
```

| 언커먼 | 10 |
| 레어 | 15 |
| 에픽 | 25 |
| 전설 | 40 |
| 신화 | 60 |

## 히어로 편성 데이터

| 항목 | 값 |
| --- | ---: |
| 최대 출전 영웅 | 8명 |
| 프리셋 수 | 3개 |
| 하위 탭 | 편성, 특성, 석상, 인장, 유물 |

1차 구현에서는 편성 탭만 실제 UI로 구현한다. 사이드킥과 좌측 석상 슬롯은 제외한다.
미출전 영웅 카드의 `+` 버튼을 누른 뒤 원하는 출전 슬롯을 클릭하면 해당 슬롯에 배치한다. 대상 슬롯에 이미 영웅이 있으면 새 영웅으로 교체한다. 출전 슬롯과 출전 중인 목록 카드의 `-` 버튼을 누르면 편성에서 제외한다. 신규 계정의 1번 프리셋은 시작 전투용 기본 편성으로 취급하고, 저장 이력이 없는 다른 프리셋은 빈 슬롯으로 표시한다. 편성 변경은 화면 안에서 임시 반영하고, 히어로 화면 이탈 시 저장 확인 팝업에서 확인을 누를 때 프리셋별 슬롯을 로컬 저장한다. 저장이 확정되면 현재 스테이지를 다시 시작한다.

## 적 최종 수치 공식

```text
일반 적 HP = floor(적 기본 HP * 스테이지 HP 배율)

보스 HP = floor(보스 기본 HP * 스테이지 HP 배율)
```

성장 레벨업 UI는 `1x`, `10x`, `100x`, `1000x` 단위를 제공한다. 단위 선택 버튼은 골드 보유량과 관계없이 항상 선택 가능하다. 선택한 단위 전체 비용을 낼 수 있을 때만 구매하고, 골드가 부족한 성장 행은 회색으로 표시한다. 회색 성장 행을 누르면 `골드가 부족합니다.` 문구를 띄운다. 성장 행의 오른쪽 버튼 문구는 `10x UP` 같은 액션 문구가 아니라 해당 단위의 업그레이드 비용만 표시한다.

보스 스테이지는 오프라인 보상 기준으로 사용하지 않는다. 현재 위치가 보스라면 직전 일반 스테이지를 기준으로 계산한다.

| 스테이지 구간 | 초당 골드 기준 |
| --- | ---: |
| 1-1 ~ 1-4 | 현재 스테이지 처치 골드 * 0.20 |
| 1-5 ~ 1-8 | 현재 스테이지 처치 골드 * 0.25 |
| 1-9 ~ 1-12 | 현재 스테이지 처치 골드 * 0.30 |
| 1-13 ~ 1-16 | 현재 스테이지 처치 골드 * 0.35 |
| 1-17 ~ 1-19 | 현재 스테이지 처치 골드 * 0.40 |

```text
오프라인 보상 = floor(초당 골드 기준 * 오프라인 초)
최대 오프라인 초 = 28800
```
