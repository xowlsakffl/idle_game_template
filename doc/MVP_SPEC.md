# 1차 MVP 기획서

## 게임 한 줄 설명

세로 화면에서 영웅들이 자동으로 적을 처치하고, 유저는 골드와 뽑기를 통해 영웅을 성장시키는 방치형 카드 수집 RPG.

## 핵심 가정

검증되지 않은 가정은 다음과 같다.

- 유저가 직접 조작하지 않아도 성장 선택만으로 재미를 느낄 것이다.
- 단순한 영웅 3명만으로도 자동전투 루프 검증이 가능하다.
- 뽑기는 캐릭터 수집보다 성장 재료 공급 장치로 먼저 작동해야 한다.
- 오프라인 보상은 콘텐츠 부족을 완화하지만, 실제 콘텐츠를 대체하지는 못한다.

이 가정들이 틀리면 그래픽을 올려도 게임성은 살아나지 않는다.

## 목표 플랫폼

- 1차 개발: Unity Editor 플레이 모드
- 1차 빌드 목표: Android
- 화면 방향: Portrait
- 입력 방식: 터치 기준, 마우스 클릭으로도 테스트 가능해야 함

## 메인 화면 구조

세로형 한 화면에서 다음 영역을 가진다.

```text
┌────────────────────┐
│ 재화 / 스테이지 정보 │
├────────────────────┤
│                    │
│   자동전투 영역     │
│   영웅 vs 적        │
│                    │
├────────────────────┤
│ 영웅 성장 패널       │
├────────────────────┤
│ 뽑기 / 메뉴 버튼     │
└────────────────────┘
```

## 핵심 루프

```text
자동전투 진행
→ 적 처치
→ 골드 획득
→ 영웅 레벨업
→ 전투력 상승
→ 더 높은 스테이지 도달
→ 뽑기로 영웅 조각 또는 중복 보상 획득
→ 성장 가속
```

## 전투 규칙

- 전투는 완전 자동으로 진행된다.
- 영웅은 일정 공격 주기마다 현재 적을 공격한다.
- 적 HP가 0 이하가 되면 적 처치로 처리한다.
- 적 처치 시 골드를 지급한다.
- 스테이지마다 정해진 처치 수를 채우면 다음 스테이지로 이동한다.
- 영웅 전원이 죽는 시스템은 1차 MVP에서 제외한다.
- 패배, 회귀, 환생 시스템은 1차 MVP에서 제외한다.

## 영웅 규칙

- 영웅은 총 3명으로 시작한다.
- 모든 영웅은 기본 보유 상태로 시작한다.
- 영웅은 골드로 레벨업한다.
- 레벨업 시 공격력이 증가한다.
- 스킬, 장비, 속성, 포지션은 1차 MVP에서 제외한다.

## 적 규칙

- 적은 총 5종이다.
- 스테이지에 따라 적 HP와 보상이 증가한다.
- 적 종류는 시각적 구분과 기본 이름만 가진다.
- 적의 공격, 디버프, 특수 패턴은 1차 MVP에서 제외한다.

## 스테이지 규칙

- 총 20개 스테이지를 제공한다.
- 각 스테이지는 적 10마리 처치 시 클리어된다.
- 스테이지가 오를수록 적 HP와 골드 보상이 증가한다.
- 20 스테이지 클리어 후에는 20 스테이지를 반복한다.

## 골드 규칙

- 골드는 적 처치, 오프라인 보상으로 획득한다.
- 골드는 영웅 레벨업에 사용한다.
- 골드 이외의 재화는 1차 MVP에서 최소화한다.

## 뽑기 규칙

- 뽑기는 무료 재화 또는 테스트 버튼으로 실행한다.
- 1회 뽑기와 10회 뽑기를 지원한다.
- 결과는 영웅 조각 또는 중복 성장 재료로 처리한다.
- 1차 MVP에서는 유료 결제, 천장, 픽업, 배너 교체를 제외한다.

## 저장 규칙

로컬 저장 대상은 다음이다.

- 현재 스테이지
- 현재 골드
- 영웅별 레벨
- 영웅별 조각 수
- 마지막 접속 시간

저장 방식은 Unity `PlayerPrefs` 또는 JSON 파일 중 하나를 사용한다.

1차 MVP에서는 구현 속도를 위해 `PlayerPrefs`를 우선 사용해도 된다. 다만 데이터가 늘어나면 JSON 저장으로 옮기는 것이 낫다.

## 오프라인 보상 규칙

- 게임 종료 또는 백그라운드 진입 시 마지막 접속 시간을 저장한다.
- 재접속 시 현재 시간과 마지막 접속 시간의 차이를 계산한다.
- 오프라인 보상은 현재 스테이지 기준 초당 골드 생산량으로 계산한다.
- 최대 누적 시간은 8시간으로 제한한다.

```text
오프라인 골드 = min(오프라인 초, 28800) * 현재 스테이지 초당 골드
```

## 1차 MVP 제외 항목

아래 기능은 지금 넣으면 개발 속도를 크게 늦추고, 핵심 루프 검증에 직접 필요하지 않다.

- 계정 로그인
- 서버 저장
- PvP
- 길드
- 채팅
- 장비
- 스킬 강화
- 속성 상성
- 일일 퀘스트
- 업적
- 출석 보상
- 상점
- 광고 보상
- 인앱 결제
- 환생/전직/승급
- 고급 연출과 컷신

## MVP 완료 기준

다음 조건을 모두 만족하면 1차 MVP 완료로 본다.

- 새 게임 시작 후 자동전투가 즉시 진행된다.
- 적 처치 시 골드가 증가한다.
- 골드로 영웅 레벨을 올릴 수 있다.
- 영웅 레벨업 후 적 처치 속도가 빨라진다.
- 스테이지 1부터 20까지 진행할 수 있다.
- 뽑기를 실행하면 결과가 나오고 영웅 조각이 증가한다.
- 앱을 종료 후 재실행해도 진행 데이터가 유지된다.
- 일정 시간 뒤 재접속하면 오프라인 보상이 지급된다.
