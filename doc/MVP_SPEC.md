# 1차 MVP 기획서

## 게임 한 줄 설명

세로 화면에서 영웅들이 자동으로 적을 처치하고, 유저는 골드, 뽑기, 스테이지 선택을 통해 성장 속도와 파밍 위치를 관리하는 방치형 카드 수집 RPG.

## 핵심 구조 수정

이 게임의 스테이지 핵심은 단순한 `1~20` 진행이 아니다.

정확한 MVP 기준은 다음이다.

- 접속하면 자동전투가 바로 시작된다.
- 현재 진행 가능한 스테이지에서 몬스터 할당량을 채우면 다음 스테이지로 자동 이동한다.
- 챕터 1은 `1-1`부터 `1-20`까지 구성한다.
- `1-20`은 일반 몬스터 스테이지가 아니라 보스 스테이지다.
- 보스를 제한 시간 안에 잡으면 챕터 1 클리어로 처리한다.
- 보스를 잡지 못하면 `1-19`로 돌아가 계속 반복 파밍한다.
- 유저가 특정 스테이지를 직접 선택하면 자동 진행을 멈추고 해당 스테이지만 반복한다.

이 구조가 없으면 히어로 수집형 방치 게임의 핵심 압박이 약해진다. 막히는 지점, 성장 목표, 반복 파밍 위치가 분명해야 유저가 레벨업과 뽑기를 할 이유가 생긴다.

## 목표 플랫폼

- 1차 개발: Unity Editor 플레이 모드
- 1차 빌드 목표: Android
- 화면 방향: Portrait
- 입력 방식: 터치 기준, 마우스 클릭으로도 테스트 가능해야 함

## 메인 화면 구조

```text
┌────────────────────┐
│ 골드 / 스테이지 / 모드 │
├────────────────────┤
│                    │
│   자동전투 영역      │
│   영웅 3명 vs 적     │
│                    │
├────────────────────┤
│ 영웅 성장 패널        │
├────────────────────┤
│ 스테이지 / 뽑기 버튼  │
└────────────────────┘
```

## 진행 모드

### 자동 진행 모드

기본 모드다.

```text
현재 스테이지 전투
→ 몬스터 할당량 처치
→ 다음 스테이지 자동 이동
→ 1-20 도달
→ 보스전
→ 성공 시 챕터 클리어
→ 실패 시 1-19 반복 파밍
```

### 선택 스테이지 반복 모드

유저가 이전에 도달한 스테이지를 선택하면 진입한다.

```text
유저가 스테이지 선택
→ 해당 스테이지 전투
→ 몬스터 할당량 처치
→ 같은 스테이지 다시 시작
→ 유저가 자동 진행 재개를 누르기 전까지 반복
```

선택 스테이지 반복 모드는 방치 파밍용이다. 이 모드에서는 다음 스테이지로 자동 이동하지 않는다.

## 핵심 루프

```text
자동전투 진행
→ 적 처치
→ 골드 획득
→ 영웅 레벨업
→ 전투력 상승
→ 더 높은 스테이지 도달
→ 보스 도전
→ 실패 시 직전 스테이지 반복 파밍
→ 성장 후 보스 재도전
```

## 전투 규칙

- 전투는 완전 자동으로 진행된다.
- 영웅은 일정 공격 주기마다 현재 적을 공격한다.
- 적 HP가 0 이하가 되면 적 처치로 처리한다.
- 적 처치 시 골드를 지급한다.
- 일반 스테이지는 정해진 몬스터 할당량을 모두 처치하면 완료된다.
- 보스 스테이지는 보스 1마리를 제한 시간 안에 처치하면 완료된다.
- 영웅 전원이 죽는 시스템은 1차 MVP에서 제외한다.
- 보스 실패 조건은 `제한 시간 초과`로만 처리한다.

## 스테이지 규칙

- 1차 MVP는 챕터 1만 구현한다.
- 챕터 1은 `1-1`부터 `1-20`까지 총 20개 스테이지다.
- `1-1`부터 `1-19`까지는 일반 스테이지다.
- `1-20`은 보스 스테이지다.
- 일반 스테이지는 몬스터 10마리 처치 시 클리어된다.
- 자동 진행 모드에서는 일반 스테이지 클리어 후 다음 스테이지로 이동한다.
- 선택 스테이지 반복 모드에서는 일반 스테이지 클리어 후 같은 스테이지를 다시 시작한다.
- `1-20` 보스 실패 시 자동으로 `1-19` 반복 파밍 상태가 된다.
- 챕터 1 클리어 후에는 1차 MVP 기준으로 `1-20` 클리어 상태를 표시하고 `1-19` 또는 유저 선택 스테이지를 반복한다.

## 보스 규칙

- `1-20`에 보스 1종이 등장한다.
- 보스전 제한 시간은 30초다.
- 제한 시간 안에 보스 HP를 0으로 만들면 성공이다.
- 제한 시간 안에 잡지 못하면 실패다.
- 실패 시 획득 보상은 없다.
- 실패 후 진행 위치는 `1-19`로 되돌린다.
- 유저가 성장한 뒤 자동 진행 재개를 누르면 다시 `1-20`에 도전할 수 있다.

## 영웅 규칙

- 영웅은 총 3명으로 시작한다.
- 모든 영웅은 기본 보유 상태로 시작한다.
- 영웅은 골드로 레벨업한다.
- 레벨업 시 공격력이 증가한다.
- 스킬, 장비, 속성, 포지션은 1차 MVP에서 제외한다.

## 적 규칙

- 일반 적은 총 5종이다.
- 스테이지 구간에 따라 등장 적이 바뀐다.
- 적의 HP와 보상은 스테이지별 배율로 증가한다.
- 적의 공격, 디버프, 특수 패턴은 1차 MVP에서 제외한다.

## 골드 규칙

- 골드는 일반 적 처치와 오프라인 보상으로 획득한다.
- 보스 실패 시 골드는 지급하지 않는다.
- 골드는 계정 능력 성장에 사용한다.
- 히어로 레벨업은 골드가 아니라 히어로 경험치 아이템을 사용한다.
- 골드 이외의 재화는 1차 MVP에서 최소화한다.

## 능력 성장 규칙

능력 성장은 계정 단위 성장이다. 히어로 레벨과 분리한다.

1차 MVP에서 실제 계산에 먼저 반영할 능력은 다음이다.

- 공격력
- 치명타 확률
- 치명타 데미지

아래 능력은 목표 구조에는 포함하지만 1차 MVP에서는 데이터만 남기고 실제 계산은 미룬다.

- 체력
- 더블 치명타 확률
- 더블 치명타 추가 데미지
- 최종 데미지

## 뽑기 규칙

- 뽑기는 뽑기권을 우선 소모한다.
- 뽑기권이 부족하면 부족한 횟수만큼 루비 보석을 소모한다.
- 1회 뽑기와 10회 뽑기를 지원한다.
- 결과는 영웅 조각으로 처리한다.
- 목표 뽑기 종류는 이벤트 뽑기, 히어로 뽑기, 인장 뽑기, 장비 뽑기다.
- 1차 MVP에서는 히어로 뽑기만 먼저 실제 구현한다.
- 1차 MVP에서는 유료 결제, 천장, 픽업, 배너 교체를 제외한다.

## 저장 규칙

로컬 저장 대상은 다음이다.

- 현재 골드
- 최고 도달 스테이지
- 현재 파밍 스테이지
- 현재 진행 모드
- 보스 클리어 여부
- 영웅별 레벨
- 영웅별 조각 수
- 마지막 접속 시간

저장 방식은 Unity `PlayerPrefs` 또는 JSON 파일 중 하나를 사용한다.

1차 MVP에서는 구현 속도를 위해 `PlayerPrefs`를 우선 사용해도 된다. 다만 진행 모드와 스테이지 상태가 늘어나므로, MVP 이후에는 JSON 저장으로 옮기는 것이 낫다.

## 오프라인 보상 규칙

- 게임 종료 또는 백그라운드 진입 시 마지막 접속 시간을 저장한다.
- 재접속 시 현재 시간과 마지막 접속 시간의 차이를 계산한다.
- 오프라인 보상은 현재 파밍 스테이지 기준 초당 골드 생산량으로 계산한다.
- 보스 스테이지에서는 오프라인 보상을 계산하지 않고, 직전 일반 스테이지 기준으로 계산한다.
- 최대 누적 시간은 8시간으로 제한한다.

```text
오프라인 골드 = floor(min(오프라인 초, 28800) * 현재 파밍 스테이지 초당 골드)
```

## 1차 MVP 제외 항목

- 계정 로그인
- 서버 저장
- PvP
- 길드
- 채팅
- 장비
- 스킬 강화
- 속성 상성
- 일일 퀘스트
- 업적
- 출석 보상
- 상점
- 광고 보상
- 인앱 결제
- 환생/전직/승급
- 챕터 2 이상
- 고급 연출과 컷신

## MVP 완료 기준

다음 조건을 모두 만족하면 1차 MVP 완료로 본다.

- 새 게임 시작 후 자동전투가 즉시 진행된다.
- `1-1` 일반 몬스터 10마리 처치 후 `1-2`로 자동 이동한다.
- 일반 스테이지는 자동 진행 모드에서 다음 스테이지로 이동한다.
- 유저가 특정 스테이지를 선택하면 그 스테이지만 반복한다.
- `1-20`에서 보스가 등장한다.
- 보스 제한 시간 초과 시 `1-19` 반복 파밍으로 돌아간다.
- 골드로 영웅 레벨을 올릴 수 있다.
- 레벨업 후 보스 재도전 성공 가능성이 올라간다.
- 뽑기를 실행하면 결과가 나오고 영웅 조각이 증가한다.
- 앱을 종료 후 재실행해도 진행 모드와 스테이지 상태가 유지된다.
- 일정 시간 뒤 재접속하면 현재 파밍 스테이지 기준 오프라인 보상이 지급된다.
