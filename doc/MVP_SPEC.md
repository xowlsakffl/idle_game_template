# 룬 슬롯 해금 규칙

- 룬은 한 프리셋에 최대 4개까지 장착한다.
- 1번 슬롯은 기본 개방한다.
- 2번 슬롯은 계정 Lv.20, 3번 슬롯은 계정 Lv.50, 4번 슬롯은 계정 Lv.100에 해금한다.
- 잠긴 슬롯에 저장된 룬은 전투 계산에 적용하지 않는다.
- 룬에는 레벨과 룬조각/룬가루 재화가 없다.
- 합성은 같은 룬 + 같은 등급 여러 개를 소비한다. 필요 수량은 커먼 10개, 언커먼 30개, 레어 80개, 에픽 200개, 전설 500개다.
- 룬 탭에는 선택 룬 합성과 일괄 합성을 제공한다.

# 편성 장착 규칙

- 편성 탭은 영웅 8칸과 룬 4칸을 다룬다.
- 토템은 장착 개념을 폐기하고, 보유한 6종 효과가 항상 전체 적용된다.
- 룬 슬롯을 누르면 편성 화면 위에 선택 모달을 띄운다.
- 모달에서 이미 해당 프리셋에 임시 장착된 룬은 `장착됨`으로 표시한다.
- 편성 탭에서 바꾼 영웅/룬은 즉시 저장하지 않는다.
- 편성 탭을 나가거나 닫을 때 저장 확인 팝업을 띄운다.
- 확인하면 영웅/룬을 한 번에 저장하고 현재 스테이지를 다시 시작한다.
- 취소하면 임시 변경을 버리고 저장된 편성으로 되돌린다.
- 토템 탭은 강화와 전체 진화용이다. 룬 탭은 승급과 정보 확인용이다.

# 메뉴 패널 규칙

- 성장 메뉴만 기존처럼 전투 영역을 줄이는 하단 성장 패널로 유지한다.
- 하단 대메뉴는 `성장, 영웅, 요새, 시설, 소환, 배틀, 상점` 순서로 둔다.
- 영웅, 요새, 시설, 소환, 배틀, 상점, 디버그 계열 메뉴는 전투 화면 위에 올라오는 팝업형 패널로 연다.
- 열린 메뉴 탭을 다시 누르면 닫힌다.

# 1차 MVP 기획서

## 게임 한 줄 설명

세로 화면에서 영웅들이 자동으로 적을 처치하고, 유저는 골드, 뽑기, 스테이지 선택을 통해 성장 속도와 파밍 위치를 관리하는 방치형 카드 수집 RPG.

## 핵심 구조 수정

이 게임의 스테이지 핵심은 단순한 `1~20` 진행이 아니다.

정확한 MVP 기준은 다음이다.

- 접속하면 자동전투가 바로 시작된다.
- 현재 진행 가능한 스테이지에서 몬스터 할당량 100마리를 채우면 다음 스테이지로 자동 이동한다.
- 챕터는 20스테이지 단위로 구성한다.
- 각 챕터의 `n-20`은 일반 몬스터 스테이지가 아니라 보스 스테이지다.
- 보스를 제한 시간 안에 잡으면 다음 챕터 `n+1-1`로 자동 진행한다.
- 보스를 잡지 못하면 같은 챕터 `n-19`로 돌아가 계속 반복 파밍한다.
- 유저가 특정 스테이지를 직접 선택하면 자동 진행을 멈추고 해당 스테이지만 반복한다.

## 확장 방향 반영

다음 방향은 현재 MVP 구조에 반영한다.

- 레퍼런스 방향은 영웅 수집형 방치 RPG의 전형적인 화면 밀도와 UX를 따른다.
- 원본 게임의 상표, 캐릭터, 이미지, 고유 문구를 복제하지 않고, 장르 문법과 플레이 구조만 참고한다.
- 기본 전투 속도는 `1x`, 무료 선택 속도는 `2x`다.
- `4x`는 결제 상품으로 둘 예정이지만, 지금은 결제 구현 없이 권한 플래그만 둔다.
- 일반 스테이지는 몬스터 100마리 물량을 처치하는 구조로 잡는다.
- 화면에는 100개 오브젝트를 전부 만들지 않고, 전투 계산은 처치 수 기반으로 처리한다.
- 전투 참여 영웅은 최대 8명으로 확장한다.
- 스킬은 1차로 자동 발동 쿨타임 스킬만 넣는다.
- 펫은 1차로 장착 펫 1마리의 자동 공격/보조 효과만 넣는다.
- 성장 가능, 뽑기 가능, 보스 막힘 같은 행동 가능 상태는 빨간 점 알림으로 표시한다.
- 정식 아트 리소스 전까지는 도형 기반 임시 스프라이트로 영웅/몬스터 이동, 피격, 데미지 팝업을 구현한다.
- 영웅은 중앙 전투 진형에서 시작하고, 일반 몬스터 무리는 화면 사방 외곽에서 중앙 진형으로 몰려오는 방식으로 표시한다.
- 영웅 액터는 특성별로 전장 안을 배회한다. 근접은 전방 순찰, 원거리는 후방 좌우 이동, 지원은 중앙 궤도 이동, 방어는 느린 전열 순찰로 구분한다.
- 보이는 몬스터 액터는 자기 위치에서 가장 가까운 출전 영웅을 어그로 대상으로 잡고, 해당 영웅 주변으로 접근한다.
- 보이는 영웅 액터는 공격 대상 몬스터를 한 번 잡으면 그 몬스터가 죽을 때까지 같은 대상을 추적하고 공격한다. 대상이 죽어 새 몬스터가 들어온 뒤에만 다음 대상을 다시 고른다.
- 영웅과 몬스터 액터는 목표 좌표를 즉시 대입하지 않고 현재 표시 좌표에서 이동한다. 영웅 이동 속도는 해당 영웅의 `MoveSpeed` 스탯을 반영한다.
- 상단 단일 몬스터 HP 게이지는 사용하지 않는다. 일반 스테이지 상단 바는 100마리 처치 진행률을 표시하고, 각 보이는 몬스터 액터 위에 작은 HP바를 표시한다.
- 일반 스테이지는 여러 표시 몬스터 HP 슬롯을 동시에 유지한다. 몬스터가 죽으면 100마리 총량이 남아 있는 동안 죽은 수만큼 새 몬스터가 사방 외곽 스폰 위치에서 다시 진입한다.
- 새로 진입 중인 몬스터는 짧은 등장 보호 시간을 가지며, 화면에 들어오기 전 공격 대상으로 잡히지 않는다. 몬스터가 죽으면 새 스폰이 나타나기 전에 짧은 `KO` 사망 표시를 보여준다.
- 전투 영역에는 중앙 스테이지 배지, 가이드 퀘스트 카드, 데미지 미터기를 겹쳐 배치한다.
- 데미지 미터기는 현재 출전한 모든 영웅을 표시하고, 영웅별 직접 공격 누적 피해량을 일반 숫자와 게이지바로 보여준다.
- 데미지 미터기는 몬스터마다 초기화하지 않고, 새 스테이지가 시작될 때마다 초기화한다.

반대로 다음은 아직 하지 않는다.

- 실제 결제/IAP
- 4배속 상품 구매 플로우
- 수동 스킬 조작
- 스킬 강화, 펫 성장, 펫 뽑기
- 몬스터 100마리의 실제 GameObject 동시 생성

이 구조가 없으면 영웅 수집형 방치 게임의 핵심 압박이 약해진다. 막히는 지점, 성장 목표, 반복 파밍 위치가 분명해야 유저가 레벨업과 뽑기를 할 이유가 생긴다.

## 목표 플랫폼

- 1차 개발: Unity Editor 플레이 모드
- 1차 빌드 목표: Android
- 화면 방향: Portrait
- 입력 방식: 터치 기준, 마우스 클릭으로도 테스트 가능해야 함

```text
┌────────────────────┐
│ 골드 / 스테이지 / 모드 │
├────────────────────┤
│                    │
│   자동전투 영역      │
│   영웅 최대 8명 vs 적 무리 │

├────────────────────┤
│ 영웅 성장 패널        │
```

## 진행 모드

### 자동 진행 모드

기본 모드다.

```text
현재 스테이지 전투
→ 몬스터 100마리 처치
→ 다음 스테이지 자동 이동
→ n-20 도달
→ 보스전
→ 성공 시 다음 챕터 진입
→ 실패 시 n-19 반복 파밍
```

### 선택 스테이지 반복 모드

유저가 이전에 도달한 스테이지를 선택하면 진입한다.

```text
유저가 스테이지 선택
→ 해당 스테이지 전투
→ 몬스터 할당량 처치
→ 같은 스테이지 다시 시작
→ 유저가 자동 진행 재개를 누르기 전까지 반복
```

선택 스테이지 반복 모드는 방치 파밍용이다. 이 모드에서는 다음 스테이지로 자동 이동하지 않는다.

## 핵심 루프

```text
자동전투 진행
→ 적 처치
→ 골드 획득
→ 영웅 레벨업
→ 전투력 상승
→ 더 높은 스테이지 도달
→ 보스 도전
→ 실패 시 직전 스테이지 반복 파밍
→ 성장 후 보스 재도전
```

## 전투 규칙

- 전투는 완전 자동으로 진행된다.
- 영웅은 일정 공격 주기마다 현재 락온한 적을 공격한다. 한 번 잡은 대상은 죽을 때까지 바꾸지 않는다.
- 같은 전투 틱에 공격 준비가 끝난 출전 영웅은 먼저 전부 수집한 뒤 한 묶음으로 처리한다. 앞 슬롯 영웅이 먼저 처치했다고 뒤 슬롯 영웅의 쿨다운이나 공격 묶음이 누락되면 안 된다.
- 적 HP가 0 이하가 되면 적 처치로 처리한다.
- 적 처치 시 골드를 지급한다.
- 일반 스테이지는 몬스터 100마리를 모두 처치하면 완료된다.
- 보스 스테이지는 보스 1마리를 제한 시간 안에 처치하면 완료된다.
- 영웅 HP, 피격, 부활 표시는 구현하되, 영웅 전멸로 인한 스테이지 실패 조건은 1차 MVP에서 제외한다.
- 보스 실패 조건은 `제한 시간 초과`로만 처리한다.

## 스테이지 규칙

- 스테이지는 `챕터-번호` 형식이며 챕터마다 20개 스테이지를 가진다.
- 각 챕터의 `1~19`번은 일반 스테이지다.
- 각 챕터의 `20`번은 보스 스테이지다.
- 일반 스테이지는 몬스터 100마리 처치 시 클리어된다.
- 자동 진행 모드에서는 일반 스테이지 클리어 후 다음 스테이지로 이동한다.
- 선택 스테이지 반복 모드에서는 일반 스테이지 클리어 후 같은 스테이지를 다시 시작한다.
- 보스 실패 시 자동으로 같은 챕터의 `19`번 일반 스테이지 반복 파밍 상태가 된다.
- `1-20` 이후 스테이지는 고정 테이블을 추가하지 않고 절차 생성한다. 몇 년 운영을 가정하면 고정 스테이지 20개로는 진행/보상/수치 검증이 불가능하다.

## 보스 규칙

- 각 챕터 `20`번 스테이지에 보스 1종이 등장한다.
- 보스전 제한 시간은 30초다.
- 제한 시간 안에 보스 HP를 0으로 만들면 성공이다.
- 제한 시간 안에 잡지 못하면 실패다.
- 실패 시 획득 보상은 없다.
- 실패 후 진행 위치는 같은 챕터의 `19`번 일반 스테이지로 되돌린다.
- 유저가 성장한 뒤 자동 진행 재개를 누르면 다시 해당 챕터 보스에 도전할 수 있다.

## 영웅 규칙

- 1차 영웅 데이터는 커먼부터 전설까지 등급별 6명씩, 신화는 8명 이상 확장 가능한 등급으로 시작하고, 전투 출전은 최대 8명으로 제한한다.
- 신규 계정은 커먼 시작 영웅 6명만 기본 보유 상태로 시작한다. 나머지 영웅은 뽑기 조각을 1개 이상 얻어야 보유 상태가 된다.
- 영웅 등급은 커먼, 언커먼, 레어, 에픽, 전설, 신화로 나눈다. 신화 등급은 서비스 확장에 따라 6명 이상으로 계속 추가할 수 있다.
- 영웅 특성은 근접, 원거리, 지원, 방어로 나눈다.
- 영웅은 기본 스탯으로 공격력, 체력, 공속, 이속을 가진다.
- 영웅은 공격력, 체력, 공속, 이속 중 하나를 강화하는 기본 패시브를 가진다.
- 기본 패시브와 보유 효과는 낮은 누적 보너스로 둔다. 영웅 1명 획득만으로 공격력 10~15%가 오르는 구조는 초반 전투 밸런스를 무너뜨리므로, 보유 공격력 효과는 영웅 1명당 0.5%, 성급 1개당 0.08% 기준으로 시작한다.
- 등급은 단순 색상이 아니라 능력치와 레벨업 비용 계수에 반영한다. 높은 등급은 스탯이 높지만 성장 비용도 더 비싸야 장기 수집 구조가 유지된다.
- 모든 영웅은 0성에서 시작하고 최대 15성까지 올릴 수 있다.
- 성급 표시는 항상 5칸으로 표시한다. 1~5성은 노란별이 채워지고, 6~10성은 노란 5칸 위에 파란별이 왼쪽부터 덮이며, 11~15성은 파란 5칸 위에 보라별이 왼쪽부터 덮인다. 예: 6성은 첫 번째 별만 파란색, 오른쪽 4개는 노란색이다.
- 영웅 레벨 상한은 0성 50레벨에서 시작하고, 성급 1개당 50레벨씩 증가한다. 1성 상한은 100레벨이고, 15성 최종 상한은 800레벨이다.
- 5성 효과는 해당 영웅의 기본 패시브를 강화하고, 10성 효과는 공격력/체력/공속/이속 전체 스탯 보너스를 연다.
- 영웅 탭은 편성, 특성, 토템, 룬 4개 하위 탭으로 나눈다.
- 1차 구현은 편성 탭과 특성 탭을 구현하고, 사이드킥은 제외한다. 토템은 편성 슬롯이 아니라 전역 성장 탭으로 관리한다.
- 편성 탭은 최대 8명 출전과 프리셋 3개를 지원한다.
- 특성 탭은 계정 레벨로 획득한 특성 포인트를 소모해 올린다. 계정 경험치와 계정 레벨은 영웅 레벨과 분리한다.
- 특성 트리는 19개 뎁스를 가로로 진행한다. 뎁스별 노드 수는 `1, 3, 3, 1, 2, 2, 1, 3, 3, 2, 1, 2, 1, 3, 3, 3, 1, 2, 1`이다.
- 다음 뎁스 전체가 해금되는 구조가 아니라, 선으로 연결된 이전 뎁스 노드 중 하나를 MAX까지 올려야 해당 노드를 찍을 수 있다.
- 특성 효과는 공격력, 체력, 치명타 데미지, 최종 데미지, 스킬 데미지, 받는 피해 감소, 이동속도, 골드 획득량, 경험치책 획득량, 계정 경험치 획득량에 반영할 수 있다.
- 특성은 장기 성장축이므로 노드 하나 MAX 기준 보통 4~12% 범위로 제한한다. 피해감소와 이동속도는 체감이 강하므로 더 낮게 둔다.
- 신규 계정의 1번 프리셋은 시작 전투용 기본 편성으로 취급하고, 저장 이력이 없는 다른 프리셋은 빈 슬롯으로 표시한다.
- 영웅 목록은 한 줄에 6명씩 배치하고, 낮은 등급부터 표시하며, 같은 등급 안에서는 이름 가나다순으로 정렬한다.
- 편성 탭에서 미출전 영웅 카드의 `+` 버튼을 누른 뒤 원하는 출전 슬롯을 클릭하면 해당 슬롯에 배치한다.
- 대상 슬롯에 이미 영웅이 있으면 새로 선택한 영웅으로 교체한다.
- 출전 중인 영웅은 목록 카드 중앙에 `배치됨` 문구를 오버레이로 띄우고 카드 전체를 어둡게 표시한다.
- 출전 슬롯과 출전 중인 목록 카드의 우측 상단 `-` 버튼을 누르면 편성에서 제외한다.
- `자동 배치` 버튼은 현재 보유 영웅을 전투력 높은 순서로 정렬해 최대 8명까지 편성 초안에 채운다.
- `일괄 승급` 버튼은 조각이 충분한 모든 영웅을 가능한 성급까지 즉시 승급하고 저장한다.
- 영웅 카드 또는 편성 슬롯의 영웅을 클릭하면 상세 정보 화면을 연다.
- 상세 정보 화면은 전투력, 현재 보유 경험치책, 스킬 정보, 공격력, 체력, 공속, 이속, 5성/10성 해금 효과를 표시한다.
- 상세 정보 화면의 기본 정보 탭은 하단 탭 바로 위에 `제외`, `레벨업`, `승급` 버튼을 둔다. `제외`는 편성 초안에서만 제거하고, `레벨업`은 경험치책, `승급`은 해당 영웅 조각을 소모한다.
- 상세 정보 화면의 장비 슬롯은 무기, 모자, 갑옷, 장신구, 포션 5개만 표시한다. 6번째 슬롯은 아직 구현하지 않는다.
- 상세 정보 화면 하단은 `기본 정보`, `장비`, `초월` 3개 탭으로 나눈다.
- `장비` 탭은 보유 장비 카드를 표시하고, 무기/모자/갑옷/장신구/포션 필터를 제공한다.
- 장비 카드는 영웅 편성과 동일하게 `+`로 선택하고, 캐릭터 주변의 같은 부위 슬롯을 누르면 장착한다. 이미 장착 중인 장비는 `장착중` 문구와 어두운 카드로 표시하고, 카드나 슬롯의 `-` 버튼으로 해제한다.
- 캐릭터 주변 장비 슬롯을 누를 때 선택 장비가 없으면 `장비` 탭으로 이동하고 해당 슬롯 장비만 필터링한다.
- 편성 변경은 영웅 화면 내부에서만 임시 반영된다. 화면을 나갈 때 `저장하시겠습니까?` 팝업을 띄우고, 확인을 누르면 저장 후 현재 스테이지를 다시 시작한다.
- 영웅 뽑기에서 같은 영웅을 얻으면 해당 영웅 조각으로 전환된다.
- 영웅 조각이 성급업 요구량 이상이면 조각을 소모해 성급을 올릴 수 있다.
- 성급은 공격력과 체력에 직접 보너스를 준다.
- 영웅은 영웅 경험치 아이템으로 레벨업한다.
- 레벨업 시 공격력과 체력이 증가한다.
- 수동 스킬 조작, 장비 세트 효과, 속성, 포지션은 1차 MVP에서 제외한다. 장비 스탯의 전투 밸런스 최종 반영은 장비 성장 속도 검증 뒤 확정한다.

## 숫자 표기 규칙

- 전투력, 공격력, 체력, 피해량, 골드, 경험치책 표시는 A~Z/AB 축약 단위를 쓰지 않고 `1,234` 형태의 일반 숫자로 통일한다.
- `999,999`는 시스템 상한이 아니라 초중반 숫자 규모를 읽기 쉽게 유지하기 위한 소프트 목표값이다. 수치를 잘라내지 않고 스테이지 보상 성장률, 레벨업 비용, 등급/성급 배율을 낮춰 인플레이션을 제어한다.
- HP, 데미지, 골드, 경험치책은 내부적으로 `GameNumber`를 유지한다. 장기 운영 성장은 숫자 무한 팽창보다 던전, 룬, 시설 파견, 세트 효과, 프레스티지 같은 별도 성장축으로 분산한다.
- 루비와 뽑기권처럼 소량 보유 개수를 읽는 재화도 같은 일반 숫자로 표시한다.

## 스킬 규칙

- 1차 MVP의 스킬은 유저가 누르는 액티브 스킬이 아니라 자동 발동 스킬이다.
- 스킬은 쿨타임이 끝나면 현재 락온한 타깃에게 피해를 준다. 타깃이 죽은 뒤에만 새 타깃을 잡는다.
- 스킬 강화, 스킬 슬롯 편성, 스킬 연출은 이후로 미룬다.

## 펫 규칙

- 1차 MVP에서는 기본 장착 펫 1마리만 둔다.
- 펫은 일정 주기마다 현재 락온한 타깃을 자동 공격한다. 타깃이 죽은 뒤에만 새 타깃을 잡는다.
- 펫은 소량의 전투 보조 효과를 줄 수 있다.
- 펫 수집, 펫 성장, 펫 뽑기는 이후로 미룬다.

## 전투 속도 규칙

- `1x`와 `2x`는 무료로 선택 가능하다.
- `4x`는 결제 권한이 있을 때만 선택 가능하다.
- 1차 MVP에서는 결제 구현 없이 권한 플래그만 둔다.
- 전투 화면의 배속 UI는 버튼 하나로 제공하고, 클릭할 때마다 `1x -> 2x -> 4x -> 1x` 순서로 순환한다.
- `4x` 권한이 없으면 `2x` 다음 클릭은 잠긴 `4x`를 건너뛰고 `1x`로 돌아간다.
- 전투 화면 하단 오른쪽에는 `스킬 자동`, `피버 자동`, `가속` 3개 버튼을 나란히 배치한다.
- `스킬 자동`은 자동 스킬 발동 여부를 실제로 켜고 끈다. `피버 자동`은 피버 게이지/피버 효과 구현 전까지 상태 저장 토글만 제공한다.
- QA용 시간 배속은 실제 상품 배속과 분리한다.

## 적 규칙

- 일반 적은 총 5종이다.
- 스테이지 구간에 따라 등장 적이 바뀐다.
- 적의 HP와 보상은 스테이지별 배율로 증가한다.
- 적의 공격, 디버프, 특수 패턴은 1차 MVP에서 제외한다.

## 골드 규칙

- 골드는 일반 적 처치와 오프라인 보상으로 획득한다.
- 보스 실패 시 골드는 지급하지 않는다.
- 골드는 계정 능력 성장에 사용한다.
- 영웅 레벨업은 골드가 아니라 영웅 경험치 아이템을 사용한다.
- 골드 이외의 재화는 1차 MVP에서 최소화한다.

## 능력 성장 규칙

능력 성장은 계정 단위 성장이다. 영웅 레벨과 분리한다.

1차 MVP 성장 능력은 다음 7종으로 잡는다.

- 공격력 증가: 최대 1,000레벨, 만렙 수치 +3,000
- 체력 증가: 최대 1,000레벨, 만렙 수치 +18,000
- 치명타 확률 증가: 최대 500레벨, 만렙 수치 50.0%
- 치명타 데미지 증가: 최대 1,000레벨, 기본 5.0% + 레벨당 0.2%
- 더블 치명타 확률 증가: 최대 500레벨, 만렙 수치 50.0%
- 더블 치명타 추가 데미지 증가: 최대 1,000레벨, 기본 5.0% + 레벨당 0.2%
- 최종 데미지 증가: 최대 1,000레벨, 레벨당 0.1%

공격력, 치명타, 더블 치명타, 최종 데미지는 전투 피해 계산에 반영한다.
체력은 영웅 HP와 몬스터 공격 계산에 반영한다. 다만 전멸 패배가 없으므로 지금은 생존 압박의 시작점이고, 실제 실패 조건은 보스 제한 시간으로 유지한다.
치명타 확률과 더블 치명타 확률은 최대 레벨이 500으로 짧고 50% 캡이 있으므로, 초반 만렙을 막기 위해 공격력/체력보다 레벨당 비용 곡선을 높게 잡는다.
성장 레벨업은 `1x`, `10x`, `100x`, `1000x` 단위로 선택해 실행할 수 있어야 한다.
선택한 단위 전체 비용이 부족하면 강화 버튼은 회색으로 표시하고, 누르면 `골드가 부족합니다.` 문구를 띄운다.
단위 선택 버튼 자체는 부족 여부와 관계없이 항상 선택 가능해야 한다. 성장 행 오른쪽에는 `10x UP` 같은 액션 문구 대신 선택 단위 기준 업그레이드 비용만 표시한다.

## 뽑기 규칙

- 뽑기는 뽑기권을 우선 소모한다.
- 뽑기권이 부족하면 부족한 횟수만큼 루비 보석을 소모한다.
- 1회 뽑기와 10회 뽑기를 지원한다.
- 결과는 등급 확률에 따라 영웅을 선택하고, 뽑기 1회당 해당 영웅 조각 1개로 처리한다.
- 영웅와 장비 뽑기는 공통 등급 확률표를 사용한다. 등급 확률은 커먼 45%, 언커먼 30%, 레어 15%, 에픽 7%, 전설 2.5%, 신화 0.5%로 시작한다.
- 목표 뽑기 종류는 이벤트 뽑기, 영웅 뽑기, 룬 뽑기, 장비 뽑기다.
- 1차 MVP에서는 영웅 뽑기와 장비 뽑기를 실제 구현한다.
- 장비 뽑기는 장비 뽑기권을 우선 소모하고, 부족한 횟수는 루비 100개씩 소모한다.
- 장비 뽑기 결과는 장비별 보유 수량, 레벨, 성급 상태로 저장한다. 신규 장비 상태는 0성 1레벨에서 시작한다.
- 장비 레벨 상한은 영웅과 동일하게 `(성급 + 1) * 50`으로 둔다. 0성 상한은 50, 1성 상한은 100, 15성 상한은 800이다.
- 장비 장착/해제 UI와 영웅별 장착 저장은 구현한다. 강화 UI/재료와 장비 스탯 전투 반영은 다음 단계로 분리한다.
- 1차 MVP에서는 유료 결제, 천장, 픽업, 배너 교체를 제외한다.

## 저장 규칙

로컬 저장 대상은 다음이다.

- 현재 골드
- 최고 도달 스테이지
- 현재 파밍 스테이지
- 현재 진행 모드
- 보스 클리어 여부
- 영웅별 레벨
- 영웅별 조각 수
- 영웅별 성급
- 마지막 접속 시간

저장 방식은 Unity `PlayerPrefs` 또는 JSON 파일 중 하나를 사용한다.

1차 MVP에서는 구현 속도를 위해 `PlayerPrefs`를 우선 사용해도 된다. 다만 진행 모드와 스테이지 상태가 늘어나므로, MVP 이후에는 JSON 저장으로 옮기는 것이 낫다.

## 오프라인 보상 규칙

- 게임 종료 또는 백그라운드 진입 시 마지막 접속 시간을 저장한다.
- 재접속 시 현재 시간과 마지막 접속 시간의 차이를 계산한다.
- 오프라인 보상은 현재 파밍 스테이지 기준 초당 골드 생산량으로 계산한다.
- 보스 스테이지에서는 오프라인 보상을 계산하지 않고, 직전 일반 스테이지 기준으로 계산한다.
- 최대 누적 시간은 8시간으로 제한한다.

```text
오프라인 골드 = floor(min(오프라인 초, 28800) * 현재 파밍 스테이지 초당 골드)
```

## MVP 완료 기준

다음 조건을 모두 만족하면 1차 MVP 완료로 본다.

- 새 게임 시작 후 자동전투가 즉시 진행된다.
- `1-1` 일반 몬스터 100마리 처치 후 `1-2`로 자동 이동한다.
- 일반 스테이지는 자동 진행 모드에서 다음 스테이지로 이동한다.
- 유저가 특정 스테이지를 선택하면 그 스테이지만 반복한다.
- `1-20`에서 보스가 등장한다.
- 보스 제한 시간 초과 시 같은 챕터 19번 스테이지 반복 파밍으로 돌아간다.
- 영웅 경험치 아이템으로 영웅 레벨을 올릴 수 있다.
- 영웅 조각이 충분하면 성급을 올릴 수 있다.
- 레벨업 후 보스 재도전 성공 가능성이 올라간다.
- 뽑기를 실행하면 결과가 나오고 영웅 조각이 증가한다.
- 앱을 종료 후 재실행해도 진행 모드와 스테이지 상태가 유지된다.
- 일정 시간 뒤 재접속하면 현재 파밍 스테이지 기준 오프라인 보상이 지급된다.
## 토템 강화

토템은 `영웅 > 토템` 탭에서 관리한다. 장착 슬롯 개념은 폐기하고, 보유한 토템 6종의 효과가 항상 전투와 보상 계산에 모두 적용된다.

토템의 목적은 “추가 장비 슬롯”이 아니라 계정 전체 장기 성장축이다. 기본 토템은 전투/수호/지원/비전/폭풍/지휘 6개 카테고리로 제공한다. 각 토템은 커먼 등급으로 시작하고, 같은 등급의 6개 토템을 모두 `Lv.100`까지 강화해야 다음 등급으로 전체 진화할 수 있다. 전체 진화 시 해당 등급의 모든 토템이 다음 등급 `Lv.1`이 된다.

1차 구현 범위:

- 토템 6종 카테고리 데이터
- 커먼~신화 등급 진화 구조
- 토템 정수 재화
- 등급별 토템 레벨 1~100
- 장착 없이 모든 토템 효과 전체 적용
- 같은 등급 6종 Lv.100 달성 후 전체 진화
- 영웅 하단 `토템` 탭 UI
- 토템 강화 버튼 길게 누르기
- 토템 전체 진화
- 전투 계산 반영: 공격력, 치명타 확률, 보스전 공격력, 체력, 피해 감소, 골드, 경험치책, 계정 경험치, 공속, 이속, 스킬 피해, 스킬 쿨타임
- 디버그 버튼: 토템 정수 지급, 토템 기본 보유 처리

제외 범위:

- 토템 성급 또는 중복 조각
- 토템 뽑기
- 토템 스킨
- 토템 장착 슬롯
- 토템 전용 던전
## 룬 규칙

룬은 영웅 탭의 하단 `룬` 페이지에서 관리한다.

- 프리셋마다 룬 4개를 장착한다.
- 슬롯은 가로 4칸 고정으로 보여준다.
- 같은 프리셋 안에서 같은 룬을 중복 장착할 수 없다.
- 룬에는 레벨과 조각 재화가 없다.
- 룬은 등급별 개별 보유 수량을 저장하고, 같은 룬 + 같은 등급 여러 개를 합성해 다음 등급 룬 1개를 만든다.
- 합성 요구량은 커먼 10개, 언커먼 30개, 레어 80개, 에픽 200개, 전설 500개다.
- 룬 장착, 해제, 최고 등급 상승이 현재 프리셋에 영향을 주면 전투 계산을 갱신하고 스테이지를 다시 시작한다.

1차 반영 효과는 공격력, 최종 피해, 체력, 받는 피해 감소, 골드, 경험치책, 계정 경험치, 공격속도, 이동속도, 스킬 피해, 스킬 쿨타임, 치명타 확률이다.

룬은 토템처럼 전역 성장축이 아니라 프리셋 선택을 만드는 장착물이다. 별도 룬조각/룬가루 재화를 두면 장비 강화와 역할이 겹치므로, 룬 자체를 획득하고 합성하는 방식만 사용한다.

## 성물 규칙 (폐기/보류)

이 섹션은 현재 MVP에서 사용하지 않는다. 기존 성물 탭은 폐기했고, 시설은 영웅 하위 탭이 아니라 별도 대메뉴로 이동했다. 성물류 장기 성장축은 토템/룬/시설과 역할이 겹치지 않는 방향으로 재기획할 때까지 보류한다.

성물은 영웅 속성을 강화하는 장기 성장축이다. 화염 성물은 화염 영웅, 냉기 성물은 냉기 영웅처럼 같은 속성 영웅에게만 적용한다.

- 속성은 화염, 냉기, 번개, 암흑, 신성, 자연 6종으로 시작한다.
- 모든 성물은 기본 제공한다.
- 성물은 장착물이 아니며 편성 저장 확인 로직을 타지 않는다.
- 성물 레벨은 0~1000이다.
- 레벨당 같은 속성 영웅 공격력 +0.02%, 체력 +0.02%를 적용한다.
- 강화 재료는 `성물 파편`이다.
- 강화에 성공하면 현재 스테이지를 다시 시작해서 전투 계산을 갱신한다.
- 1차 구현에서는 속성 상성, 속성 피해, 상태 이상, 성물 뽑기, 성물 등급을 제외한다.

이 구조를 택하는 이유는 단순 전체 공격력 보너스를 하나 더 추가하면 성장축이 과도하게 겹치기 때문이다. 성물은 “전체가 더 세지는 버튼”이 아니라 “어떤 속성 영웅 풀을 키울지 정하는 장기 투자처”로 둔다.
## 시설 파견 시스템

기존 성물 시스템은 폐기/보류한다. 시설 파견은 영웅 하위 탭이 아니라 하단 대메뉴 `시설`에서 관리한다.

- 시설은 의뢰소, 훈련소, 대장간, 토템 제단, 룬 공방, 초월 연구소 6종이다.
- 시설별 생산 자원은 각각 골드, 영웅 경험치책, 장비 경험치책, 토템 정수, 룬 상자, 초월석 하나만 가진다.
- 모든 시설의 생산 주기는 1시간이고 최대 누적 시간은 12시간이다.
- 시설 레벨은 1~20이다. Lv.1/5/10/15/20에서 배치 슬롯이 1/2/3/4/5개로 열린다.
- 업그레이드에는 골드를 쓰지 않고 목재, 벽돌, 철재를 사용한다. 자재는 시설 생산물이 아니라 사냥 보상이다.
- 업그레이드 재료 구간은 Lv.2~5 목재, Lv.6~10 목재+벽돌, Lv.11~15 벽돌+철재, Lv.16~20 목재+벽돌+철재다.
- 출전 중인 영웅도 시설에 배치할 수 있지만 같은 영웅을 여러 시설에 중복 배치할 수 없다.
- 자동배치는 전투력, 레벨, 성급, 등급만 반영한 생산 점수 순서로 채운다. 시설 선호 특성은 없다.
- 생산량은 기본 생산량 * 시설 레벨 배율 * 영웅 배치 배율이다. 시설 레벨 배율은 `1 + (레벨 - 1) * 0.08`, 영웅 배치 보너스는 시설당 최대 +50%다.
- 오프라인 시간도 시설 생산에 반영하되 12시간을 넘지 않는다.
- 시설별 수령, 모두 획득, 전체 추천 배치, 모두 해제를 제공한다.
- 시설 탭 UI는 세로 카드 리스트를 기본으로 한다.
- `배치 인력` 모달의 추천 배치는 기존 배치를 유지하고 빈 슬롯만 생산 점수 순으로 채운다.
- 일반 몬스터 처치 시 낮은 확률로 목재를 지급하고, 보스 처치 시 목재/벽돌/철재를 지급한다. 스테이지가 높아질수록 보스 자재량이 증가한다.
## ACTIVE UPDATE - Facility Dispatch replaces Relic

The previous Relic/Seongmul system is deprecated and held for later redesign. Facility Dispatch now lives in the main bottom `시설` menu, not inside the hero sub-tab list.

Facility Dispatch rules:

- Facilities: `FAC_REQUEST` 의뢰소 produces Gold, `FAC_TRAINING` 훈련소 produces Hero EXP Books, `FAC_FORGE` 대장간 produces Equipment EXP Books, `FAC_TOTEM` 토템 제단 produces Totem Essence, `FAC_RUNE` 룬 공방 produces Rune Boxes, `FAC_TRANSCEND` 초월 연구소 produces Transcend Stones.
- Every facility has a 1 hour production cycle, 12 hour max accumulation, and levels 1-20.
- Upgrade material is never Gold. Upgrade uses hunting materials only: Wood, Brick, Iron.
- Upgrade bands: Lv.2-5 Wood, Lv.6-10 Wood+Brick, Lv.11-15 Brick+Iron, Lv.16-20 Wood+Brick+Iron.
- Assignment slots unlock by facility level: Lv.1 = 1 slot, Lv.5 = 2, Lv.10 = 3, Lv.15 = 4, Lv.20 = 5.
- Deployed battle heroes can also be assigned to facilities, but the same hero cannot be assigned to multiple facilities.
- Auto assignment uses production score based only on combat power, level, stars, and rarity. There is no facility preference trait.
- Production formula: base production * facility level multiplier * hero assignment multiplier.
- Facility level multiplier starts at `1 + (level - 1) * 0.08`.
- Hero assignment bonus is capped at +50% per facility.
- Offline time is included, capped by the same 12 hour accumulation limit.
- UI exposes per-facility collect, collect all, per-facility auto assign, global recommended assignment, clear all, and upgrade/MAX state.
- Wood/Brick/Iron are gained from hunting, not from facilities. Normal monsters can drop Wood at low chance; bosses drop Wood/Brick/Iron with higher stages increasing Brick/Iron availability.
- Save data must include facility level, assigned hero ids, stored production, last production tick, and Wood/Brick/Iron wallet amounts.
